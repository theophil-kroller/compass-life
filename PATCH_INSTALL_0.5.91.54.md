# Compass Life 0.5.91.54 – Patch-Installation

**Nur auf Compass Life Source 0.5.91.53 anwenden.**

1. Vor dem Update vorhandenen Source-Stand sichern; persönliche Tresordaten nicht in Git speichern.
2. Patch-ZIP an der Wurzel des Repositories entpacken und gleichnamige Quelldateien ersetzen. Neue Test- und Release-Dateien hinzufügen.
3. Änderungen in den Standard-Branch übernehmen, GitHub Actions / GitHub Pages Deployment prüfen.
4. Nach erfolgreichem Deployment Compass neu laden; in **Insights → Gesundheit & Körper → Ernährung → Überblick** die Kategorien und das Donut-Diagramm prüfen. Teste einen anderen Zeitraum und tippe ein Segment an.
5. Bei Installation auf einem anderen Base-Stand stattdessen das vollständige Source-ZIP verwenden.

Das Patch-ZIP enthält nur neue/geänderte Dateien und löscht nichts. Ein Full Source-ZIP ist **kein** vorgebautes dist/ oder ein sofort installierbares Android-Paket.
