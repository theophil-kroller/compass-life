# Patch 0.5.91.55 installieren

1. **Nur auf Compass Life 0.5.91.54 anwenden.** Bestehende Source-Dateien sichern.
2. Das Patch-ZIP im Wurzelverzeichnis des Repositories entpacken. Geaenderte Dateien ueberschreiben; neue Dateien hinzufuegen. Keine anderen Dateien loeschen.
3. In GitHub committen und die GitHub-Actions-Pruefungen fuer GitHub Pages abwarten.
4. Danach Compass aktualisieren und pruefen: die drei Proteinbecher unter Milch-/Proteinprodukten, die Standardportionen und den manuell gestarteten Ernaehrungsreport.

Das Full-Source-ZIP kann stattdessen zur Komplettaktualisierung des Quellcodes verwendet werden. Vorhandene Nutzerdaten/Tresordaten nicht durch Repository-Dateien ersetzen.
