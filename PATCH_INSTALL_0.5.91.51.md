# Compass Life 0.5.91.51 — Installation

1. Patch **nur auf 0.5.91.50** anwenden. Andernfalls Full Source 0.5.91.51 verwenden.
2. ZIP auspacken und darin enthaltene Dateien im GitHub-Repository mit identischem Pfad ersetzen / neu hinzufügen.
3. GitHub Actions / Pages-Deployment abwarten, anschließend Compass-Seite im Browser **hart neu laden (Strg+F5)**, falls noch eine ältere PWA-Version gecacht ist.
4. In „Heute“ auf „Menü recherchieren“ klicken. Die App wechselt zu Extended → Insights → Ernährung → Mensa. Das Mensa-Panel muss jetzt ohne Warten auf den Journal-Abgleich sichtbar werden.
5. Falls ein dynamisches Modul nicht geladen werden kann, erscheint eine verständliche Fehlermeldung mit „Erneut laden“ statt des endlosen Spinners.
6. Es werden keine Menüs importiert, nur weil die Mensa-Ansicht geöffnet wird. Frühere Lebensmittel und Tagebucheinträge bleiben erhalten.
