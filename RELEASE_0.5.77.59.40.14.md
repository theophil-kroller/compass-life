# Compass Web 0.5.77.59.40.14 · Leinsamen als reguläre Kachel

Basis: Web 0.5.77.59.40.13. Bestehende GPS-, Freizeit- und Watch-Bridge-Änderungen unverändert.

- Das Sonderfeld „Gestern mit Uhrzeit nachtragen“ neben den Leinsamen wurde entfernt. Die dadurch unterbrochene vier-spaltige Kachelanordnung ist wieder konsistent.
- **SPAR Bio-Leinsamen · gekaut · 1 TL (3 g)** ist eine gewöhnliche Kachel unter Snacks, mit Grafik/Symbol und Namen; jeder Klick erfasst eine neue Portion zum aktuellen Zeitpunkt.
- Der normale Ernährungstagebuch-Editor erlaubt das Ändern von Datum, Uhrzeit, Menge und Notiz jedes einzelnen Eintrags, auch rückwirkend; kein spezieller einmaliger Nachtrag mehr.
- Die Daily-Dozen-Teilportion aus Build .13 bleibt erhalten.
- Sicherheitshinweis des Herstellers im Tooltip/Eintragsvermerk, statt als separates Bedienfeld im Kachelraster. Die Packung ist zum Kochen/Backen vorgesehen; Zerkauen ersetzt das Erhitzen nicht.

Keine Datenbank- oder Garmin-Änderung. Patch ist von **.40.13** aus anzuwenden. Nicht beide ZIP-Dateien hochladen.
