# Compass 0.5.91.24 – Patch-Installation

**Basis:** 0.5.91.23 auf GitHub `main` (BRAINEFFECT MCT C8).

1. Patch-ZIP entpacken; die enthaltenen Dateien mit unveränderter relativer Ordnerstruktur in das GitHub-Repository hochladen (nicht das ZIP als einzelne Datei).
2. GitHub Actions `Deploy Compass Web` prüfen; er muss den Vite-Build ausführen.
3. Nach Deployment den App-/Lockscreen-Versionshinweis `0.5.91.24` verifizieren.
4. Wim-Hof-Player über 15 Minuten laufen lassen; nach natürlichem Ende sollte eine verschlüsselte Einheit entstehen. Eine OS-Hintergrundsperre kann Audio unterbrechen – danach den Zwischenstand im Player fortsetzen oder explizit abschließen.
5. Für Inbox → Next Actions Zeit messen; bei wiederholten Verzögerungen im lokalen Performance-Panel messen und Export teilen (keine Aufgabentitel im Export).
6. `Insights → Ernährung → Mensa` öffnen, Wochen-E-Mail einfügen, Vorschau prüfen, bei Bedarf GPT-E-Mail-Prompt kopieren und das angereicherte JSON prüfen/importieren. Kein automatischer Gmail-Zugriff.

**Sicherheit:** Die App bleibt außerhalb einer tatsächlich laufenden Atemwiedergabe nach 15 Minuten sperrbar. Der Checkpoint ist kein fertiger Eintrag; der Vault wird nur bei nachgewiesener Wiedergabe bzw. Bestätigung aktualisiert.

**Einschränkungen:** Betriebssystem-Wake-Lock und Audio im Hintergrund sind von Browser/Gerät abhängig; kein garantierter Schlafmodus-Background-Service. Proportionen/Finanzen/Garmin/Coach bleiben unverändert.
