# Installieren: Compass Life 0.5.91.35 V-Taper Coach

**Voraussetzung:** Die bestehende GitHub-Quelle entspricht 0.5.91.34, Commit `6206d760d0145f941bdeabf61a26bac2f1c0c8eb`.

## Patch

1. Die Datei `Compass_Life_0.5.91.35_VTAPER_SCHULTERBALANCE_PATCH_FROM_0.5.91.34.zip` lokal entpacken.
2. **Nur** die enthaltenen Dateien/Verzeichnisse mit unveränderter relativer Ordnerstruktur auf `main` hochladen, vorhandene Dateien überschreiben.
3. GitHub Actions – Pages-Deploy abwarten und das Ergebnis prüfen. ZIP-Dateien selbst gehören nicht ins Repository.
4. App neu laden. Unter Trainingscoach → Trainingsziel V-Taper die Schulterbalance öffnen. Mehrere dokumentierte Tage ermöglichen die adaptive Rotation.
5. Unter Equipmentdetails → „Homegym · Kabelzug und Klimmzugstange“ sind beide Zusatzgeräte **noch nicht einsatzbereit**. Die Freigabeschalter erst nach sicherer Installation und Kontrolle der Verankerung benutzen.

Die vollständige Version ist eine unabhängige Alternative zum Patch. **Nicht beide ZIPs zusammen hochladen.**

## Kontrolle

- Bei V-Taper zu Hause max. drei Übungen im 25-Minuten-Fenster.
- Hintere Schulter durch Reverse Fly nach Bedarf; seitliche durch Dumbbell Lateral Raise, vordere indirekt bei Press-Übungen.
- Keine ungefragt hinzugefügten Front Raises. Die neue Front-Raise-Übung ist in der freiwilligen Übungsbibliothek vorhanden.
- Ohne explizite Montagefreigabe werden Kabelzugübungen und unterstützte Klimmzüge nicht für das Heimtraining geplant.
- Bestätigte Sätze bleiben im bestehenden encrypted Strength-Journal; keine automatischen „absolviert“-Markierungen.

**Hinweis:** Der echte Vite-Produktionsbuild konnte vor der Veröffentlichung lokal mangels npm-Abhängigkeiten nicht ausgeführt werden; GitHub Actions muss ihn bestätigen.
