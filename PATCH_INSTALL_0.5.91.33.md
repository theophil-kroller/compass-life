# Patch-Anleitung Compass Life 0.5.91.33

1. Sicherstellen, dass GitHub `main` auf Compass Life **0.5.91.32** steht.
2. PATCH-ZIP lokal entpacken.
3. Alle enthaltenen Pfade unter Erhalt der Ordnerstruktur in das Repository hochladen; vorhandene Dateien überschreiben, neue Dateien hinzufügen.
4. GitHub Actions > Deploy Compass Web prüfen. Bei einem fehlgeschlagenen Workflow keine einzelnen alten Jobs im selben Lauf erneut starten.
5. Nach erfolgreichem Deploy unter **Essensmenü** die zwei Skyr-Varianten und **Meine Muskatkürbis-Suppe** prüfen. Bei der Suppe die Zutatengramm und Zahl tatsächlicher Portionen editieren, sobald bekannt.

Der Patch verändert keine bestehenden Diary-Einträge. Das vollständige ZIP stellt eine alternative Quellcodebereitstellung derselben Version dar.
