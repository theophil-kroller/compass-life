# GitHub-Upload · Compass 0.5.77.37.1

**Voraussetzung: bereits installierte Version 0.5.77.37.**

1. ZIP entpacken.
2. Alle im ZIP enthaltenen Dateien unter genau diesen relativen Pfaden in dein Repository `theophil-kroller/compass-life` laden. Die vorhandene `client/vite.config.js` ersetzen; alle anderen Dateien sind neu.
3. Automatisches Deployment abwarten und Compass vollständig neu laden (bei einer installierten PWA eventuell zweimal, damit der Service Worker die neue Version übernimmt).
4. Links im Menü muss `0.5.77.37.1` stehen.
5. Unter **Insights → Ernährung → Tagebuch** sollte rechts unter dem kcal-Wert die kleine `💊 1 ohne kcal`-Pille stehen, ohne die breite Zeile.
6. Unter **Insights → Krafttraining** eine Einheit bearbeiten, einen neuen Satz anlegen und eine zuvor protokollierte Übung auswählen. Dann sollten die letzten erfassten Wiederholungen und kg erscheinen. Diese können weiterhin direkt überschrieben werden.

Ein bereits ausdrücklich gespeicherter leerer oder unbekannter Wert wird nicht als bestätigte Null interpretiert. Die neuen Werte werden nur beim aktiven Auswählen einer Übung in leeren Feldern vorgeschlagen.

**Dieses Paket enthält nur die geänderten/neuen Dateien, keine vollständige Neuanlage des Repositorys.**
