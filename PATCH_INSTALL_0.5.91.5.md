# Compass 0.5.91.5 – Installationshinweise

1. Ausgangsbasis: **Compass 0.5.91.4** (GitHub `main`-Commit `01644135791da1a67c9102729c9dabcaf62c4b4d`).
2. Patch-ZIP im Repository-Stamm entpacken: Pfade aus dem ZIP relativ zum Root-Verzeichnis übernehmen; bereits vorhandene Dateien ersetzen, neue hinzufügen.
3. Für ein komplett neues Repository stattdessen das FULL_SOURCE-ZIP verwenden. **Nicht beide Pakete gleichzeitig hochladen.**
4. Nach dem Upload GitHub Actions abwarten; Vite ist lokal nicht installiert, darum kein lokaler bundler-bestätigter Produktionsbuild.
5. Bei Nutzung der Finanzübersicht: Einnahmen/Ausgaben-Kennzahlen öffnen, dann eine Testbuchung einzeln korrigieren. Sammelbestätigung nur nach Sichtung aller Buchungstexte auswählen.

Die Vault-Daten des Nutzers sind NICHT Teil der ZIP-Dateien.
