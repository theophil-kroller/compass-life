# Patch 0.5.91.31 installieren

1. **Voraussetzung:** vollständiger GitHub-Stand 0.5.91.30.
2. ZIP entpacken, Dateien und Verzeichnisse **relativ zum Repository-Root** auf main kopieren bzw. hochladen.
3. Github Actions Deployment abwarten.
4. In Habit-Schnellmenü oder Strength-Coach „＋ Einzelübung“ öffnen, Übung suchen, Foto prüfen, Sätze wählen und starten.
5. Satz bestätigen, Gewicht und RIR erfassen, das Training abschließen. Der Datensatz erscheint danach in Strength History und Muskelkarte.

**Hinweis:** Niemals Repository-Root durch ein Unterverzeichnis ersetzen. Vollversion nur verwenden, wenn 0.5.91.30 nicht zuverlässig installiert ist.
