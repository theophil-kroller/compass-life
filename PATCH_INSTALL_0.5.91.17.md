# Compass 0.5.91.17 – Installation

**Patch-Basis:** GitHub `theophil-kroller/compass-life`, Branch `main`, Commit `a8d4951347a4da13424834ed9455b5d56fb2fe40`, Version **0.5.91.16**. Die unveränderte Ausgangsversion wurde mit dem lokalen 0.5.91.16-Full-Source-ZIP an vier Dateien einschließlich Git-Blob-Hash abgeglichen.

1. Für den Patch nur ZIP-Inhalte relativ zur **Repository-Wurzel** hochladen. Bestehende gleichnamige Dateien ersetzen. Bitte nicht beide ZIPs kombinieren.
2. Alternativ die Full-Source-Version vollständig (alle Pfade ab Repository-Wurzel) als eigenständigen neuen Stand verwenden.
3. GitHub Actions nach Upload kontrollieren. Der Vite-Produktionsbuild ist erst dann bestätigt, wenn die Action tatsächlich erfolgreich durchgelaufen ist.
4. Einstellungen und verschlüsseltes Journal erhalten; keine Datenmigration, keine automatische Ernährungs- oder Zeitbuchung. Bei Arbeitszeit-Nachträgen entsperrten Tresor verwenden.

**Hinweise:** Die neue Zeiterfassung ergänzt das verschlüsselte Zeitjournal und die angezeigte Ist-Arbeitszeit; sie verändert NICHT die Importdatei für die ursprüngliche Excel-Arbeitszeitbilanz. Schwarzer Reis wird in Daily Dozen nur dann als Vollkorn interpretiert, wenn der verwendete Reis tatsächlich schwarz und nicht poliert ist; weißer Basmati zählt nicht. Alle Mengen ohne Wiegung sind im Menü editierbare Annahmen.
